# 📚 What is an IP Address?

An IP Address (Internet Protocol Address) is a unique numerical address assigned to every device connected to a network.

It helps devices identify and communicate with each other over the internet or local network.

### 🔹 Key Points
- Every device needs an IP address for communication
- Works like a digital home address
- Contains:
  - Network address
  - Host address
- Two main versions:
  - IPv4
  - IPv6

---

## 🔹 IPv4

IPv4 is the most commonly used version of IP addressing.

### Features:
- 32-bit address
- Written as four numbers separated by dots

### Example:
```bash
192.168.1.1
```

- Each section ranges from 0–255
- Supports around 4.3 billion addresses

---

## 🔹 IPv6

IPv6 is the newer version designed to replace IPv4 due to address limitations.

### Features:
- 128-bit hexadecimal address
- Uses both numbers and letters

### Example:
```bash
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

- Supports a massive number of unique addresses

---

# 🌐 What Does an IP Address Do?

An IP address helps devices identify and communicate with each other on a network.

It allows data to reach the correct device.

### Example:
When you open a website, your device uses IP addresses to send and receive data from the web server.

---

# 🔒 Public vs Private IP Address

| Public IP | Private IP |
|---|---|
| Visible on the internet | Used inside local networks |
| Assigned by ISP | Assigned by router |
| Used for external communication | Used for internal communication |
| Unique worldwide | Reused in different networks |

### Common Private IP Ranges:
```bash
192.168.x.x
10.x.x.x
172.16.x.x – 172.31.x.x
```

---

# 📡 What Does a Router Do?

A router connects devices to the internet and directs traffic between networks.

### Main Functions:
- Assigns private IP addresses
- Connects local network to the internet
- Sends and receives internet traffic
- Helps secure the network

---

# 🔀 What Does a Switch Do?

A switch connects devices within the same local network.

### Main Functions:
- Allows devices to communicate internally
- Transfers data between connected devices
- Works inside LAN (Local Area Network)

---

# 🌍 Internet vs Local Network

| Internet | Local Network (LAN) |
|---|---|
| Global network | Small private network |
| Connects devices worldwide | Connects nearby devices |
| Uses public IP addresses | Uses private IP addresses |
| Managed by ISPs | Managed by routers |

# 💡 What I Learned

- Every device connected to a network needs an IP address.
- IPv4 is still widely used, but IPv6 was created because IPv4 addresses are limited.
- Routers connect local networks to the internet.
